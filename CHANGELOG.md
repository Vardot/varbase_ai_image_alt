# Changelog

All notable changes to the Varbase AI Image Alt recipe are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.0.2] - 2026-10-11
### Changed
- Add the default `.gitlab` and `.github` issue and merge request templates. See [#3614570](https://www.drupal.org/i/3614570).
- Set the recipe version to `1.0.2`.

## [1.0.1] - 2025-07-01
### Changed
- Require `drupal/ai` `~1.1.0`. See [#3532979](https://www.drupal.org/i/3532979).
- Grant `generate ai alt tags` to the Site Admin, SEO Admin, Content Admin and Editor roles. Say in `README.md` that the Varbase AI Default recipe must be applied first, and show both ways to apply this recipe: the Drupal recipe script or Drush. See [#3533377](https://www.drupal.org/i/3533377).
- Set the recipe version to `1.0.1`.

## [1.0.0] - 2025-01-26
### Added
- Initial release of the Varbase AI Image Alt recipe: installs AI, AI Image Alt Text and AI Image Bulk Alt Text to generate and fill the alt text of image fields with AI. See [#3502267](https://www.drupal.org/i/3502267).
